# 節奏樂園

單人節奏敲擊遊戲，主要在平板上玩，筆電和手機也可以。音符滑到左側的敲擊圈時，敲對應的鼓。

## 玩法

| 按鈕 | 觸控 | 鍵盤 | 音符 |
|---|---|---|---|
| 低音鼓 | 螢幕左半邊 | F | 橘色河馬 |
| 高音鼓 | 螢幕右半邊 | J | 青色鸚鵡 |

金色的連打音符敲哪一邊都算。空白鍵或 Esc 可以暫停。

## 歌曲

旋律都是傳統曲調，編曲和譜面為這個遊戲原創，音樂全部由 Web Audio 即時合成，沒有音樂檔。

| 歌曲 | 來源 | 速度 |
|---|---|---|
| 櫻花 | 日本傳統民謠 | 112 BPM |
| 聖者的行進 | 美國紐奧良傳統靈歌 | 126 BPM |
| 水手之歌 | 英語傳統水手號子 | 140 BPM |

## 在本機執行

不需要安裝或建置。在這個資料夾執行內建的小型伺服器，再用瀏覽器開啟 http://localhost:8765/

```powershell
powershell -NoProfile -File .\serve.ps1
```

加上 `-Lan` 後，同一個網路內的平板可以連到這台電腦。

## 測試

伺服器啟動後開啟 http://localhost:8765/test.html ，頁面會列出每一項測試的結果。

## 程式結構

- `js/core.js`：譜面解析、判定和計分規則
- `js/songs.js`：歌曲、伴奏和譜面資料
- `js/audio.js`：音訊時鐘、排程和合成樂器
- `js/game.js`：畫面、輸入和遊戲流程
